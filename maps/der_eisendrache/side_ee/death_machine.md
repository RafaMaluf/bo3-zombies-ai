# death_machine

## overview

There is a free Death Machine power-up easter egg in the pyramid room.

To activate it, you must wall-run on the blue square facing the Pack-a-Punch machine during an anti-gravity sequence. If done correctly, a Death Machine power-up appears above the crafting table in the same room.

## steps

1. Go to the pyramid room.
2. Wait for anti-gravity to activate.
3. Wall-run on the blue square facing the Pack-a-Punch machine.
4. If done correctly, a Death Machine power-up appears above the crafting table.
5. Pick it up.
