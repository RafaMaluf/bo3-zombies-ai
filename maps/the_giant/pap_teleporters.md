# pap + teleporters

## overview

To unlock Pack-a-Punch on The Giant, you need to open almost the entire map, turn on the power, and then link all 3 teleporters to the mainframe. Once all 3 are linked, Pack-a-Punch becomes available.

The teleporter system is one of the core mechanics of the map. Each teleporter must be activated from its pad, and after doing so you have a short time window to run back to the mainframe in spawn and interact with it. You must repeat this process for all 3 teleporters.

## power

Before doing the teleporter step, you need to open the map far enough to reach the power switch and turn it on.

### Steps
1. Open the map toward the power area.
2. Turn on the power.  
   Related image: images/pap/power_switch.jpg

## teleporter system

There are 3 teleporters on the map, all of which must be linked to the mainframe in spawn.

The easiest way to understand their positions is to use the teleporter map.

### Teleporter locations
- Teleporter A: near the Laboratory / Animal Testing side
- Teleporter B: near the Furnace Room side
- Teleporter C: on the opposite side of the facility, connected through the courtyard route toward the upper area

Related image: images/pap/teleporters_map.webp

### Mainframe location
The mainframe is at spawn and is the place you must return to after activating each teleporter.

Related image: images/pap/mainframe_at_spawn.webp

## how to link a teleporter

The process is the same for all 3 teleporters.

### Steps
1. Go to one of the 3 teleporter pads.  
   Related image: images/pap/teleporter_example.jpg
2. Interact with the teleporter.
3. As soon as you activate it, you have about 30 seconds to run back to the mainframe at spawn.
4. Interact with the mainframe before the timer runs out.
5. That teleporter is now linked.
6. Repeat the same process for the other 2 teleporters.

Important note:
- Every time you successfully link a teleporter, a power-up will spawn in the courtyard.

## unlocking Pack-a-Punch

After all 3 teleporters are linked to the mainframe, Pack-a-Punch becomes available.

### Full progression summary
1. Open almost the entire map.
2. Turn on the power.
3. Activate Teleporter A and run back to the mainframe in time.
4. Activate Teleporter B and run back to the mainframe in time.
5. Activate Teleporter C and run back to the mainframe in time.
6. Once all 3 are linked, Pack-a-Punch is unlocked.

## practical note

Because The Giant is a compact map, this process is simple once you know the layout, but for a new player the teleporter map is very useful for understanding where each pad is and how the routes connect through the facility and courtyard.
