# dragon strike

## overview

The **Dragon Strike Controller** is a special tactical-style support item on Gorod Krovi. It works similarly to an air strike, calling down dragon fire onto a targeted location and pulling zombies toward that point.

It is also required for several later map systems, including easter egg progression and its own upgrade path.

This file covers:
- how to obtain the base **Dragon Strike Controller**
- how to upgrade it into the stronger version

## part 1 - obtain the Dragon Strike Controller

To get the Dragon Strike, go to the Pack-a-Punch / Hatchery area. Upstairs, there is a console that starts the lockdown.

Important note:
- **every player in the game** must interact with the console within **10 seconds**

If done correctly, a lockdown begins. You will be trapped in the building and must survive several waves of enemies.

### what happens during the lockdown
- there are **4 rounds** of enemies
- zombies, manglers, and valkyries can spawn
- during the first 3 waves, only one window opens at a time
- in the final wave, enemies can come from all sides

### practical note
A **Ray Gun Mark 3** makes this step much easier, but it is not mandatory.

### steps
1. Reach the Hatchery / Pack-a-Punch area.
2. Go upstairs to the Dragon Strike console.
3. Have all players interact with it within 10 seconds.
4. Survive the lockdown waves.
5. Return to the console.
6. Pick up the **Dragon Strike Controller**.

## using the Dragon Strike

Once obtained, the Dragon Strike functions like a targeted strike:
- throw / use it on a location
- zombies get drawn there
- dragon fire hits that area

It is very useful for:
- crowd control
- certain trial objectives
- some easter egg and side easter egg steps
- later upgrade progression

## part 2 - upgrade the Dragon Strike

The upgraded Dragon Strike:
- deals more damage
- can store **2 charges** instead of only 1

Important note:
- even with the upgraded version, **Max Ammo** or a new round only restores **1 charge at a time**

## upgrade step 1 - get kills with the Dragon Strike

First, you need **40 kills** using the Dragon Strike.

When completed, you should hear a loud dragon roar.

### steps
1. Use the Dragon Strike repeatedly on zombie groups.
2. Reach 40 total kills with it.
3. Listen for the dragon roar confirming progress.

## upgrade step 2 - burn the flags

After the kill requirement, you must hit a certain number of flags with the Dragon Strike.

The number of required flags depends on player count:
- **1 player:** 1 flag
- **2 players:** 2 flags
- **3 players:** 3 flags
- **4 players:** 4 flags

The flags are located outside the playable area.

### known flag locations
- near **Quick Revive / spawn**
- in the **Tank Factory**
- in **Dragon Command**
- in the **Supply Depot**

### steps
1. Find one of the valid flag locations.
2. Use the Dragon Strike so the dragon fire burns the flag.
3. Repeat until the correct number of flags is completed for your player count.

## upgrade step 3 - complete the second lockdown

After the flags are done, return to the Hatchery and use the same console again.

This starts another lockdown.

Important note:
- during this lockdown, you **must use your Dragon Strike once each wave**
- if you fail to do that, you may have to restart the upgrade process

### steps
1. Return to the Hatchery console.
2. Activate it again.
3. Survive the lockdown.
4. Use the Dragon Strike during each wave.
5. After completion, return to the console.
6. Pick up the **upgraded Dragon Strike Controller**.

Related image: images/dragon_strike/5retrieveupgrade.jpg

## full progression summary

### to get the base Dragon Strike
1. Go to the Hatchery console.
2. Have all players interact within 10 seconds.
3. Survive the lockdown.
4. Pick up the Dragon Strike Controller.

### to upgrade it
1. Get 40 kills with the Dragon Strike.
2. Burn the required number of flags depending on player count.
3. Return to the Hatchery console.
4. Complete the second lockdown.
5. Use the Dragon Strike during each wave.
6. Pick up the upgraded Dragon Strike.
