# shield upgrade

## overview

The upgraded shield on Gorod Krovi is **Tiamat's Maw**.

This side file exists only as a quick reference. The full step-by-step upgrade process is already documented in:

- `shield.md`

## what the upgrade does

Compared to the base **Guard of Fafnir**, the upgraded shield:
- has better durability
- fires stronger blasts
- uses red fire instead of green
