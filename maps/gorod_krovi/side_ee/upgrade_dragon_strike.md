# upgrade dragon strike

## overview

The upgraded Dragon Strike is a stronger version of the base Dragon Strike Controller.

This side file exists only as a quick reference. The full upgrade process is already documented in:

- `dragon_strike.md`

## what the upgrade does

The upgraded Dragon Strike:
- deals more damage
- stores 2 charges instead of 1

Important note:
- Max Ammo or a new round still only restores 1 charge at a time
