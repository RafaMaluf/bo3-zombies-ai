# extra perk

## overview

One of the main side easter eggs on The Giant lets you reveal an extra perk machine hidden under the snow pile in the map. To do this, you need Monkey Bombs and all 3 teleporters linked to the mainframe.

After that, you throw a Monkey Bomb into each teleporter and teleport it back to the mainframe. When all 3 are done, you press the red button at the mainframe to activate the giant robot laser, which melts the snow pile and reveals the perk machine.

## requirements

Before starting, make sure you have:
- unlocked and linked all 3 teleporters
- obtained Monkey Bombs from the Mystery Box

## step 1 - throw Monkey Bombs into the teleporters

You need to throw one Monkey Bomb into each of the 3 teleporters and send it back to the mainframe.

### Steps
1. Go to one teleporter.
2. Throw a Monkey Bomb into it.  
   Related image: images/extra-perk/monkey_bomb_in_teleporter.jpg
3. Teleport it back to the mainframe.
4. Repeat this for the other 2 teleporters.

Important note:
- each successful teleporter will activate one panel light at the mainframe

## step 2 - check the mainframe lights

At the mainframe in spawn, each teleporter completed will turn one light from red to green.

### Steps
1. Return to the mainframe after using the teleporters.
2. Check the control panel.
3. Make sure all 3 lights are green.  
   Related image: images/extra-perk/panel_3_greens.jpg

## step 3 - fire the laser

Once all 3 lights are green, press the red button at the mainframe. This activates the giant robot laser.

### Related image
- images/extra-perk/laser.jpg

## reward

The laser melts the snow pile in the map and reveals the hidden perk machine.

### Related image
- images/extra-perk/perk_unlocked.jpg

## important note

The revealed perk can be either Stamin-Up or Deadshot
